# Ôn Mạng Máy Tính 🌸

Web luyện trắc nghiệm Mạng máy tính theo chương — 7 chương × 40 câu (12 nhận biết · 16 thông hiểu · 12 vận dụng), có giải thích từng câu.

- Chế độ **Luyện tập** (chấm ngay) và **Thi thử** (tính giờ 40 phút)
- **Đề tổng hợp** trộn cả 7 chương, giữ tỉ lệ 3-4-3
- Lưu điểm cao nhất trên trình duyệt

Chạy local: mở `index.html` hoặc `python -m http.server`.
